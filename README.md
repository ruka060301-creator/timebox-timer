# タイムボックス・タイマー

集中と休憩を区切って作業するためのシンプルなポモドーロ／タイムボックス・タイマーです。
`index.html` 1ファイルだけで動作し、ビルドや外部依存はありません。

## 使い方

`index.html` をブラウザで開くだけです。

## 機能

- **3つのモード**: 作業 / 小休憩 / 長休憩
- **円形ダイヤル**で残り時間を可視化
- **統計**（当日のみ、日付が変わるとリセット）
  - 完了ポモ … 完了した作業セッション数
  - 集中分 … 作業に費やした合計分
  - サイクル … 長休憩に到達した回数
- **設定**（歯車アイコンから開閉）
  - 作業 / 小休憩 / 長休憩それぞれの長さ（分）
  - 長休憩までのポモ数
  - 次のセッションを自動で開始
  - 終了音（Web Audio によるチャイム）
- 設定と当日の統計は `localStorage`（キー: `timebox.v1`）に保存されます

## キーボードショートカット

| キー | 動作 |
|---|---|
| `Space` | スタート / 一時停止 |
| `R` | リセット |
| `S` | スキップ（現在のセッションを完了扱いにして次へ） |

入力欄にフォーカスがあるときはショートカットは無効になります。

## 動作環境

Web Audio API と `prefers-color-scheme` に対応したモダンブラウザ（ライト／ダークは OS 設定に追従）。
